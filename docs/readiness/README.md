# Development Readiness Gate

Status: NOT READY FOR DEVELOPMENT

This registry is the mandatory pre-development gate. Existing project documentation remains authoritative; these readiness templates track whether the required BA, design, project-management, development/architecture, and QA information has been completed and approved.

## Gate rules

A project may be marked Ready for Development only when:
- [ ] Business Analysis template is complete and approved.
- [ ] UI/UX Design template is complete and approved where UI is in scope.
- [ ] Project Management template is complete and approved.
- [ ] Development & Architecture template is complete and technically reviewed.
- [ ] QA template is complete and testability has been reviewed.
- [ ] No blocking open decisions remain.
- [ ] Required source documents are linked from the role templates.

## Role documents

- `business-analysis.md` — Business Analyst
- `ui-ux-design.md` — UI/UX Designer
- `project-management.md` — Project Manager
- `development-architecture.md` — Developer / Architect
- `quality-assurance.md` — QA

## Status convention

Use one of: `TODO`, `DRAFT`, `REVIEW`, `APPROVED`, `N/A`.

Do not change this document to READY until every mandatory role document is APPROVED and every unresolved blocker is closed.
